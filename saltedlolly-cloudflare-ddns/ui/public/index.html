IPv6 and Proxied are both on. Cloudflare normally connects to your Umbrel over IPv4, but over IPv6 it would reach port 443, which is umbrelOS, unless a Cloudflare Origin Rule sends it to your reverse proxy's port. See the IPv6 Support help in Edit Config.
This must be a Cloudflare API token (not an API key), which can be obtained from the API Tokens page. Use the Edit zone DNS template to create a token. The less secure API key authentication is deliberately not supported.
Enter one or more fully qualified domain names (FQDNs) separated by commas. For example, "example.org,www.example.org,example.io". Domains do not have to share the same DNS zone. The app points these names at your home and takes over their A (and, with IPv6 on, AAAA) records. If your main domain (such as example.com) already points at a website or service hosted elsewhere, use a subdomain such as home.example.com instead. More about choosing a name
If enabled, visitors connect to Cloudflare, which hides your home IP address and can cache webpages. Turning it off publishes your home IP address in DNS for anyone to see; only do that for services that are not websites (for example an email server, which must not be proxied).
In most cases, there should be no need to turn this off, except for the rare situation where your network only uses IPv6. While this is off, the app removes the A (IPv4) records for your domains.
Leave this off unless you need it. With Proxied on, Cloudflare already serves visitors over IPv6. An IPv6 (AAAA) record points straight at your Umbrel, not at your router, so visitors arrive on port 443, which belongs to umbrelOS rather than a reverse proxy such as NPMplus. Turn it on if your internet connection has no public IPv4 address of its own (CGNAT), or for a service you publish directly on its own port. For websites behind a reverse proxy you then also need a Cloudflare Origin Rule that sends traffic to your proxy's port, and your router must allow incoming IPv6 to that port. While this is off, the app removes the AAAA (IPv6) records for your domains. More about IPv6
