Authentik

⏳ Checking...

Authentik is a single sign-on (SSO) and identity provider platform. With NPMplus, it puts a secure login in front of the apps you publish to the internet: an alternative to Umbrel's own login that works for other people too, each with their own account and access. It supports modern sign-in methods such as passkeys and two-factor authentication, and standard protocols including OpenID Connect (OIDC), OAuth2 and SAML. Learn more

How to protect a site with Authentik

Step 1: Give Authentik a public address

Do this first, once you've signed in to Authentik and secured your admin account with a passkey or an authenticator app (see the Setup Guide). People sign in on a page at an address of your own, such as auth.yourdomain.com:

  1. DNS: point auth.yourdomain.com at your home's public IP address, the same way as your other published sites. If you use Cloudflare and your home doesn't have a fixed IP address, the Cloudflare DDNS app keeps the address up to date.
  2. In NPMplus: add a proxy host for auth.yourdomain.com: scheme http, forward hostname 10.21.0.1, port 9810, and request a TLS certificate.
  3. In Authentik (open it at the new address): set https://auth.yourdomain.com in System → Settings → Base URL, and in Applications → Outposts → authentik Embedded Outpost → Edit → Advanced settings (authentik_host).

Step 2: Protect each site

It depends on the app.

If the app supports OpenID Connect (OIDC)

Look for "OpenID Connect", "OIDC" or "SSO" in the app's login settings. Set it up by following the app's own documentation and Authentik's integration guides, then publish the app in NPMplus as a normal proxy host with Auth Request: none.

If the app has no login, or no OIDC

NPMplus can check with Authentik before letting anyone reach the site ("forward auth"):

  1. In Authentik: Applications → Applications → Create with provider. Choose Proxy Provider, mode Forward auth (single application), and set External host to the site's public address (e.g. https://tools.yourdomain.com). Under Bindings, choose who may use it.
  2. In Authentik: Applications → Outposts → authentik Embedded Outpost → Edit, and add the new application.
  3. In NPMplus: on the site's proxy host, set Auth Request to authentik and save.

Important: forward auth works only for people using a web browser. Mobile apps and other programs that connect to the site directly can't show Authentik's login page, so they're blocked. If other apps use the site's API (for example with an API key), add a Custom Location for its API path with Auth Request set to none.

Be careful what you share

Authentik decides who gets in; once in, people can do whatever the app allows.

  1. If you don't need to share an app, don't. If only you use it, use it over Tailscale (or on your home network) behind your Umbrel login instead. Never publish apps that control your Umbrel or its files, even behind Authentik: for example Portainer, terminals, file managers with access to your Home folder, NPMplus's own admin page, or the Umbrel dashboard.
  2. If you must share an app that normally uses your Umbrel login (most apps without a login of their own), forward its proxy host to the app's container, not to its Umbrel port. Otherwise visitors also get your Umbrel's login page. To find the container name and port:
    • Open the app's page in the Umbrel App Store: its app ID is the last part of the page's address (for example librespeed).
    • Open its docker-compose.yml on GitHub: for apps from the official store, github.com/getumbrel/umbrel-apps/blob/master/<app-id>/docker-compose.yml (for a community store, that store's own repository).
    • Under app_proxy, use APP_HOST as the forward hostname and APP_PORT as the port (for LibreSpeed: librespeed_server_1 and 8080).
    This only works for apps on the same Umbrel as NPMplus.

Install the Authentik app from this app store to use it.

🚀 Quick Setup Guide

  1. Point your domain to your public IP

    Create DNS records (A/AAAA) pointing to your router's public IP address.

  2. Forward ports on your router
    Protocol External Port Internal Port Purpose
    TCP 80 50080 HTTP (redirect to HTTPS)
    TCP 443 50443 HTTPS
    UDP 443 50443 HTTP/3
  3. Create proxy hosts in NPMplus

    Open the NPMplus admin interface and configure your proxy hosts with SSL certificates.
