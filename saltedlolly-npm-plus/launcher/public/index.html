How to restart NPMplus:

  1. Go to your Umbrel dashboard
  2. Click on the NPMplus app tile
  3. Click the ⋮ (three dots) menu in the top right
  4. Select "Restart"
  5. Return here to see the integration enabled

🚀 Quick Setup Guide

  1. Point your domain to your public IP

    Create DNS records (A/AAAA) pointing to your router's public IP address.

  2. Forward ports on your router
    Protocol External Port Internal Port Purpose
    TCP 80 50080 HTTP (redirect to HTTPS)
    TCP 443 50443 HTTPS
    UDP 443 50443 HTTP/3
  3. Create proxy hosts in NPMplus

    Open the NPMplus admin interface and configure your proxy hosts with SSL certificates.
