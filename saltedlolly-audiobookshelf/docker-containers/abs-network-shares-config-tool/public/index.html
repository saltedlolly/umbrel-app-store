ℹ️   How it works:

  • Add your network shares containing media in the Umbrel Files app
  • All shares below are accessible in Audiobookshelf at /media/network/<host>/<share>
  • Check the box for shares that are required — Audiobookshelf will wait for them to become available before starting
  • Leave unchecked network shares that Audiobookshelf does not use — the app will start without waiting for them
  • Important: Audiobookshelf will only start if all the required network shares are available
  • Bookmark this page to quickly diagnose problems if Audiobookshelf won't start
